# 玉珂diy手作微信小程序

面向实体 DIY 手作门店的微信小程序项目，用于承接门店展示、体验预约、课程活动、成品购买、玉石手作、定制需求、会员沉淀与后台运营。当前品牌名暂定为“玉珂diy手作”，后续可替换。

## 项目定位

本项目不是普通商城，也不是单一预约工具，而是一个适合玉石、陶艺、木工、香氛、材料包和手作课程的组合型门店系统。

核心目标：

- 展示门店空间、作品质感和品牌氛围。
- 支持玉石串珠、玉石挂件等手作体验与商品展示。
- 支持到店制作体验预约。
- 支持成品和材料包购买。
- 支持课程活动报名。
- 支持定制需求提交、报价、定金和交付跟踪。
- 支持会员、优惠券、积分和复购运营。

## 设计方向

整体风格参考微信小程序轻量交互、Apple Human Interface Guidelines 的清晰与克制，以及成熟小程序的交易闭环设计。

关键词：

- 精美但不繁复。
- 温润但不松散。
- 可爱但不幼稚。
- 有手作温度，也有清晰商业路径。

视觉建议：

- 背景：暖米白、浅暖灰。
- 主行动色：鼠尾草绿。
- 辅助强调：陶土红、蜂蜜黄、柔粉。
- 图片重点：真实门店、材料细节、制作过程、用户成品。
- 页面结构：首屏直接出现品牌氛围和“立即预约 / 逛逛成品”核心行动。

详见 [DESIGN_REFERENCE.md](DESIGN_REFERENCE.md)。

## 构建与运行

当前已建立静态 Demo 脚手架，暂不接真实后端和支付。

可运行命令：

```bash
npm run lint
npm test
npm run build
npm run verify
```

命令说明：

- `npm run lint`：校验小程序页面文件、基础配置和常见跳转风险。
- `npm test`：校验 mock 数据和核心页面内容。
- `npm run build`：当前阶段执行同一套小程序结构校验。
- `npm run verify`：串行执行 lint、test、build。

微信开发者工具预览：

1. 打开微信开发者工具。
2. 导入当前项目目录。
3. AppID 可先使用测试号或项目实际 AppID。
4. 编译后查看首页、体验、商城、我的四个入口。
