# DIY 手作门店微信小程序

面向实体 DIY 手作门店的微信小程序项目，用于承接门店展示、体验预约、课程活动、成品购买、定制需求、会员沉淀与后台运营。

## 项目定位

本项目不是普通商城，也不是单一预约工具，而是一个适合陶艺、木工、香氛、材料包、礼盒和手作课程的组合型门店系统。

核心目标：

- 展示门店空间、作品质感和品牌氛围。
- 支持到店制作体验预约。
- 支持成品、材料包、礼盒购买。
- 支持课程活动报名。
- 支持定制需求提交、报价、定金和交付跟踪。
- 支持会员、优惠券、积分和复购运营。

## 设计方向

整体风格参考微信小程序轻量交互、Apple Human Interface Guidelines 的清晰与克制，以及成熟小程序的交易闭环设计。

关键词：

- 精美但不繁复。
- 温润但不松散。
- 可爱但不幼稚。
- 有手作温度，也有清晰商业路径。

视觉建议：

- 背景：暖米白、浅暖灰。
- 主行动色：鼠尾草绿。
- 辅助强调：陶土红、蜂蜜黄、柔粉。
- 图片重点：真实门店、材料细节、制作过程、用户成品。
- 页面结构：首屏直接出现品牌氛围和“立即预约 / 逛逛成品”核心行动。

详见 [DESIGN_REFERENCE.md](DESIGN_REFERENCE.md)。

## 核心功能

### C 端小程序

- 首页品牌展示
- 体验项目列表与详情
- 日期时段预约
- 商品商城
- 课程活动报名
- 定制需求提交
- 我的预约与订单
- 会员中心
- 优惠券与积分
- 门店地址、导航、联系

### B 端管理

- 门店信息管理
- 体验项目管理
- 时段与名额管理
- 商品与 SKU 管理
- 订单管理
- 到店核销
- 定制需求跟进
- 会员与优惠券管理
- 首页内容配置
